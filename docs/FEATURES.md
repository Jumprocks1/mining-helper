# Mining Helper Features


## mpv Integration
- Automatically hooks into mpv and displays Japanese subtitles (when available) in the web browser
    - Useful for mining/looking up with Yomitan, or using the built-in mining features
    - Similar to other mpv texthookers such as those mentioned [here](https://animecards.site/minefromanime/)

## jpdb Integration
- Parses loaded subtitles with [jpdb](https://jpdb.io/)
    - Useful for breaking down sentences and looking up the meanings for individual words.
