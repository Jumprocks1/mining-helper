Some source files are not kept in source control to keep the repo small/modular.

# Files
- kradfile.gz
    - https://www.edrdg.org/krad/kradinf.html
    - Downloaded from http://ftp.edrdg.org/pub/Nihongo/kradfile.gz
    - For https, this seems to work https://edrdg.org/pub/Nihongo/kradfile.gz
    - Can be unzipped for manual viewing, but the actual application uses the gz file
- kanjidic2.xml.gz
    - https://www.edrdg.org/wiki/index.php/KANJIDIC_Project
    - http://www.edrdg.org/kanjidic/kanjidic2.xml.gz
    - https://edrdg.org/kanjidic/kanjidic2.xml.gz
- JMdict_e.gz
    - https://www.edrdg.org/wiki/index.php/JMdict-EDICT_Dictionary_Project
    - http://ftp.edrdg.org/pub/Nihongo/JMdict_e.gz
    - https://edrdg.org/pub/Nihongo/JMdict_e.gz
- kangxi_radicals.csv
    - https://en.wikipedia.org/wiki/List_of_kanji_radicals_by_stroke_count
    - https://github.com/gambolputty/wikitable2csv
    - https://wikitable2csv.ggor.de/
    - This one has some manual cleaning
    - Don't really remember what I needed this for
